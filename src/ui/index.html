Не является диагностикой

Результат относится только к загруженному изображению клетки. Он не исключает малярию, не оценивает пациента и не предназначен для выбора лечения.

Границы системы

От изображения до клинического действия

API реализует только технический приём файла и исследовательскую классификацию отдельной клетки. Остальные звенья нельзя считать выполненными автоматически.

  1. Получаем машиночитаемую методологию…

Что проверяет API

Тип файла, encoded size, возможность безопасного декодирования и максимальную площадь изображения до передачи в ML processor.

Что API не проверяет

Диагноз пациента, качество всего мазка, вид Plasmodium, паразитемию и клинический контекст.

Конфиденциальность

Интерфейс не хранит историю и не отправляет файл сторонним frontend-сервисам. Не загружайте идентифицирующие данные.
