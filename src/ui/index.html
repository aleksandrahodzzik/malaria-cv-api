Главное ограничение

Результат не является диагностикой

Он относится только к загруженному изображению клетки, не исключает малярию, не оценивает пациента и не предназначен для выбора лечения.

  • Не patient-level
  • Не calibrated
  • Нужна проверка человеком

Принципы · 03

Что держим под контролем

A

Технический вход

MIME-тип, encoded size, безопасное декодирование, площадь изображения и инженерные QC-эвристики.

B

Честная граница

API не определяет диагноз пациента, вид Plasmodium, качество всего мазка или клинический контекст.

C

Приватность

Нет истории файлов и сторонних frontend-сервисов. Не загружайте идентифицирующие данные.
