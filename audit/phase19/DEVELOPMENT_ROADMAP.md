# Измеримый roadmap

Дата среза: 2026-07-29. Отсчёт начинается после подтверждения команды,
доступа к model/data и владельцев решений.

## 0–7 дней

Только P0: model decision, intended purpose/claims, закрытие публичной
анонимной экспозиции и real-model smoke design. Exit: нет silent substitution,
есть accountable owners и executable artifact checklist.

## 8–30 дней

Registry/revision/signature, Datasheet/Model Card, leakage-safe lineage,
evaluation/calibration/reject harness, hash lock и privacy-safe metrics. Exit:
две clean installations получают тот же artifact; evaluation protocol
фиксирует patient/slide unit и untouched test.

## 31–60 дней

External cohort, QC/OOD, patient-level protocol, T2/T3 load, staging,
authentication/global quotas. Exit: dataset/protocol locked до результата;
overload bounded; unauthorized traffic rejected.

## 61–90 дней

Prospective silent pilot, human factors, resilience/incident drills,
controlled risk/change traceability. Exit: AI не влияет на care; safety hazards
и operational failures измерены и рассмотрены ответственными владельцами.

## 3–6 месяцев

Multi-site validation; условный slide/counting R&D; market-specific regulatory
strategy/QMS; signed release lineage и PMS design. Exit: clinical targets
пройдены либо формально выдан NO-GO; никакого автоматического перехода к CDS.

Подробные deliverables, owner, dependencies, risks, effort и exit criteria:
`DEVELOPMENT_ROADMAP.csv`.

## Critical path

`intended purpose -> approved model -> reproducible inference -> lineage-safe
data -> QC/reject -> external patient validation -> silent workflow ->
regulatory/product decision`.

Performance optimization, новый UI и detection pipeline не должны обходить
critical path.
