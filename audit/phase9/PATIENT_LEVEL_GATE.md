# Patient-level safety gate

| Gate | Required evidence | Current |
|---|---|---|
| P0 Intended purpose | Population, setting, user, sample protocol | FAIL |
| P1 Acquisition | Microscope, stain, magnification, focus QC | FAIL |
| P2 Detection | Locked detector with slide-level errors | FAIL |
| P3 Aggregation | Prespecified hierarchical model and threshold | FAIL |
| P4 Validation | Independent patient-level cohort | FAIL |
| P5 Human factors | Review/escalation/override validation | FAIL |
| P6 Traceability | Code/model/data/calibration lineage | PARTIAL |

Любой FAIL в P0–P5 блокирует clinical/patient claim.
