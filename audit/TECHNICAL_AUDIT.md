# Technical audit — canonical summary

## Strengths verified

- Typed FastAPI schemas and stable error envelope.
- `/health` separated from model-aware `/ready`.
- Streamed request-body and decoded-pixel limits.
- MIME/content validation, multiframe rejection and filename sanitation.
- Bounded inference admission and explicit queue/execution timeouts.
- Privacy-safe structured logs and security/cache/version headers.
- Non-root multi-stage container design.
- Full-SHA CI actions, read-only repository permission and two Python versions.

## High technical gaps

- No approved model, real processor/label smoke or offline model package.
- No gateway identity/global quota.
- No full dependency hashes/base digest/model/container signatures.
- No protected metrics/alerts/traces/runbooks.
- No T2/T3 real-model/Docker/load/failure benchmark.
- No biological image-quality or OOD rejection.

## Implemented planning tools

- Statistics/calibration/cluster bootstrap/prevalence/selective risk.
- Rogan–Gladen and beta-binomial aggregation planning.
- Deterministic corruption suite.
- Erlang-C/Little/RAM/latency summaries.
- Governance priority/quality/RPN calculations.

These tools are tested calculations, not proof of model performance.
